# Naskah soal dari sekolah

Halaman `bank-soal.html` menautkan empat PDF dari folder ini. Taruh file aslinya
di sini dengan nama persis seperti berikut:

| Nama file | Isi |
| --- | --- |
| `persiapan-1-tka-matematika.pdf` | Naskah Soal Persiapan 1 TKA, Matematika, kelas IX, 2026/2027 |
| `pemantapan-tka-literasi-2026.pdf` | Soal Pemantapan TKA Literasi, Periode 1, 2026 |
| `pretest-tka-numerasi-2026-2027.pdf` | Soal Pretest TKA Numerasi, 2026/2027 |
| `pretest-tka-literasi-2026-2027.pdf` | Soal Pretest TKA Literasi, 2026/2027 |

Selama file belum ada, tombol Unduh akan membuka halaman kosong. Setelah PDF
disalin ke folder ini, tautannya langsung bekerja tanpa mengubah HTML.
